# kayak-wiki — 中文皮划艇知识库

**皮划艇的中文互联网，几乎是一片空白。**

这项技艺比绝大多数文字记载都老——蒙皮木框的猎舟在北极海域划行了至少上千年，最老的存世
实物藏于慕尼黑五大洲博物馆，藏品记录可追到 1577 年。可是今天，想在中文里系统地读懂
"这条船从哪来、怎么造、怎么滚"，能找到的几乎只有零星翻译帖和商品说明书。

与此同时，中文皮划艇论坛的黄金年代正在退潮：老帖子随站点消亡，长内容无家可归，
划了几十年的老手经验散落成聊天记录。

这个库为这两件事而生：**把散落的技艺收拢成一份永久的中文档案，再添上一本不断生长的划行日志。**

## 我们在造什么

**① 一条技术演变时间轴** — 从格陵兰 qajaq 的猎人之衣，到阿留申 baidarka 的分叉艏，
到英式海划革命，再到折叠艇、玻璃钢与今天的格陵兰复兴——一条线讲完一条船的前世今生。
已上线：[演变路线](https://fxmlab.top/kayak/evolution/)（格陵兰、英式两站详页已建成）。

**② 一座格陵兰专栏** — 狩猎文化史、船体构造、滚法体系、当代复兴与社群。
这是中文世界还没有人认真做过的事。

**③ 一本活的划行日志** — 每次下水一条：路线、潮汐曲线快照、水位、天气、同行者、装备。
环境数据由自制工具链自动挂接（调和模型算潮，不靠预报）。最重要的是每篇的**教训段**：
当时为什么这么决策、下次怎么改——这是经验档案区别于相册的地方。

## 它是怎么建成的

一个人 + 一个 AI + 一道交叉审稿闸门。

- **人**（dalianblue，麻醉医生，桐洲岛 / 富春江划手）：定方向、管书源、裁决每一条争议、
  拍板每一页能否公开。
- **AI**（建库的 agent 工作流）：切片入库、建页、交叉引用、矛盾标记。所有事实性页面经
  **第二个模型独立审稿**，勘误逐条裁决并留修订记录——AI 写的，AI 互查，人来终审。
- 所以站上读到的每个数字都带 `^[出处]`，每处资料分歧都并列摆出，不假装存在唯一"标准答案"。

## 只公开该公开的

版权是这个库的一等元数据。每一页、每一张图都带权利状态：**未授权的书永远留在私有层**，
公开层只有自写正文、自绘示意与获得授权的材料——例如吴树升《艺术级皮划艇建造技术》全书
（CC BY-SA 4.0 收录）、Bob Shaver 的阿留申建造摄影（经作者审阅后上线）。
公开与否，永远由人工拍板，不由模型。
