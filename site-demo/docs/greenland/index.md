# 格陵兰皮划艇：历史与构造

> 格陵兰不是"皮划艇的起源地之一"——对海划者而言，它就是皮划艇的母港。

## 历史主线（三分钟版）

格陵兰 qajaq 是因纽特狩猎经济的核心装备：艇随猎人定制，穿艇如穿衣。19-20世纪殖民
贸易与步枪改变狩猎方式，制造技艺一度濒危。1984 年 Qaannat Kattuffiat（格陵兰
皮划艇协会）成立，联合各村镇重建技艺，每年举办全国冠军赛，
滚法竞技成为文化复兴的载体。今天国际上的 Greenland Style 复兴——GP桨、蒙皮自造、
滚法研习——全部源于这场运动。

## 构造：为什么"合身"是一切的前提

| 部件 | 功能 | 对技巧的影响 |
|---|---|---|
| 舱圈（cockpit rim） | 皮口，tuilik 抽绳扎系处 | 密封起点——翻覆不进水的第一道闸 |
| 腿枕（masik） | 舱口前方的弧形横向甲板梁，膝/腿支点 | 决定入舱松紧——滚法的力量传递起点 |
| 脚蹬 (masikkut) | 脚部死点 | 复位发力链条的末端 |
| 蒙皮艇身 | 密闭浮力舱 | 翻覆不进水=滚法可行性的物理基础 |
| 桨 (ukiut) | 格陵兰桨 | 小叶面+浮力桨法体系 |
