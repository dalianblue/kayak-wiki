# 格陵兰滚法入门

> 格陵兰滚法（passive qualifiers 之外共 35 个竞赛滚法）不是花哨——是狩猎艇时代的保命技术，
> 也是今天检验"人艇合体"程度的标尺。

## 为什么从滚法入门格陵兰

新手对翻滚的恐惧本质是"翻覆=溺水"的想象。格陵兰传统直接反转这个等式：**翻覆是划行的
一部分**——练滚法的过程就是重建与水的关系。国际上通行的学习顺序（Qajaq USA 教学体系）：

1. **湿逃脱**（wet exit）——先学会安全地"输"
2. **髋部复位**（hip snap /」бомm recovery）——滚法的发动机
3. **扫桨复位**（sweep roll）——第一支完整滚法
4. **标准滚**（standard roll / kinngufik)——之后按兴趣展开

## 装备差异：为什么格陵兰艇滚法更"顺"

窄艇身+低甲板容积=复位所需扭矩更小；贴合的舱圈=力量传递无损耗。这不是玄学，是
[构造](index.md)页物理约束的直接推论——演变路线上每型艇的滚法难度都由其构造决定。
