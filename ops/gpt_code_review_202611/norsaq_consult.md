## 尺寸建议(工程起点)

- **使用原则：先做无尖头试配杆，再定接口。**以下均为现代复建建议，不是对 Nansen 记录的补充考证；尤其双孔型，孔距必须由实际凸榫间距决定，不能仅凭板长比例定孔后再硬配镖杆。建议把“一页指南”明确标成**可调整的工程复建方案，而非原件尺寸图**。【确定性：高】

- **上平面沟槽：浅圆底，不做深 U 槽。**针对杆径 **16–20 mm——工程起点（非文献值）**，可先试槽口宽 **10–14 mm——工程起点（非文献值）**、中心深 **2–3 mm——工程起点（非文献值）**。宽、深并非任意组合：用实际圆杆或等径圆模板检查截面，使杆主要露在板面上，获得浅托而不是被侧壁包住。槽沿倒圆，槽底沿全长平顺，不留台阶；接口位置不得因沟槽而削薄到易裂。**红线：不得靠夹紧杆身来实现“锁定”。**【确定性：中】

- **双孔型孔径与配合：按凸榫的“通过包络”定，不只量榫根。**若凸榫头不大于榫根，可从孔径比榫根最大直径大 **0.5–1.0 mm——工程起点（非文献值）**开始试配；这是**直径差**，不是单侧间隙。后斜凸榫在装入、退出时可能需要更大的开口包络，因此圆孔是否适用，要以实物试配为准；必要时小量修成顺退出方向的长圆孔并圆滑孔口，而不是盲目放大所有方向。**红线：不得使用倒扣、弹簧卡扣或需撬动才能解除的配合。**【确定性：中】

- **双孔型孔位：比例只供布局检查。**设板全长为 L，窄端孔中心可先布在距窄端 **0.04–0.08 L——工程起点（非文献值）**；握把附近孔中心可先布在距握把端 **0.20–0.30 L——工程起点（非文献值）**。后者应避开掌心承力区及指凹槽的最薄处。最终先确定窄端接口、把试配杆放槽，再按实际两个凸榫转印另一个孔；若转印位置落在薄弱区，应调整整体布局或镖杆接口，不应硬开孔。【确定性：低】

- **窄端宽度：**可渐变至 **25–35 mm——工程起点（非文献值）**；较大的孔、较宽的凸榫需要取宽端。作为保守布局检查，孔中心至最近自由边的距离可先要求不小于孔径的 **2 倍——工程起点（非文献值）**，但这不能替代木纹、裂纹和载荷检查。凸钮型则由凸钮根部所需余料控制，不必照搬双孔型端部尺寸。【确定性：中】

- **握把与指凹槽：**握把区长度先取 **90–120 mm——工程起点（非文献值）**；两侧指凹槽向内凹入先取 **3–5 mm——工程起点（非文献值）**，从浅处逐步修到适手。这里的“深度”是侧边向内的凹入量，不是从上平面向下开槽。凹槽应宽缓、圆滑，不能为了“贴手”切成尖锐缺口，也不能削弱近握把孔的侧壁。【确定性：中】

- **成品重量：**可把 **150–280 g——工程起点（非文献值）**作为上述常见硬木、宽端及厚度接近参考形态时的初步检查范围，而非验收门槛。超出范围先检查材料密度、实际体积和是否过度削薄；不以追求轻量为理由减薄孔缘或握把颈部。【确定性：低】

## 材料替代

- **白蜡木：优先推荐。**刚度足够、韧性好，密度中等偏高，手工开槽尚易；适合第一次复建。选纹理顺直、没有明显斜纹和节疤的干燥板料，使主木纹沿板长方向。其优点是可预期的韧性，不是“绝不会裂”。【确定性：高】

- **桦木实木：兼顾加工与均匀性。**密度和刚度适中，细密纹理便于修出平顺浅槽；比白蜡木更应仔细检查孔附近的短纹、端裂。硬枫也能用，刚度和耐磨性好，但通常更重、更费刀，作为已有锋利工具和经验者的替代较合适。【确定性：中】

- **优质桦木航空层板：尺寸稳定的现代方案。**交错铺层有利于减少沿单一纹理贯通开裂，但开槽会露出多层胶线，孔壁及槽沿更容易加工出毛刺。须用无空洞、无脱层且来源明确的产品；密度不一定比实木低，也不应称为传统材料等价物。【确定性：中】

- **沟槽通常不必衬硬木条。**整块白蜡木、桦木或硬枫的浅槽足够作为起点；衬条增加胶缝、端部台阶和起翘风险。只有软底材明显磨损或修复时才考虑嵌衬，并保持表面齐平、连续圆滑。**红线：不得让衬条凸起、松动或形成刮住杆身的边缘。**【确定性：高】

- **孔缘加固属于可选修整，不是默认必需。**完好实木先靠合理余料、孔口圆滑和正确退出轨迹工作；层板孔壁起毛或局部耐磨不足时，可在成形前嵌入足够大的硬木孔衬，胶合稳定后再钻修接口孔。小薄环未必更抗裂，金属衬套也可能把柔和木边变成刚性卡点。**红线：不能用衬套掩盖裂孔、缺肉或错误孔位。**【确定性：中】

- **不建议的材料：**普通 MDF／刨花板，因孔缘脆、受潮劣化且不耐反复冲击；带节疤、斜纹或端裂的软木板，因握把及接口区容易沿弱点破坏；质量不明的竹集成材，因胶合、条材方向及孔边表现难预测。高质量竹集成材并非绝对不可用，但不宜作为首次复建的默认材料。【确定性：高】

## 装填与掷法

- **双孔型装填顺序：**先确认试配杆的两个凸榫、板孔及槽面无毛刺和损伤；将杆放在槽上，把两个后斜凸榫同时对准对应孔；按凸榫的实际倾斜方向，轻轻压入并作必要的轴向滑移，使两处进入承力位置。若几何要求先挂窄端、再落下握把侧，可采用该顺序，但不能硬扭杆身。最后检查杆身没有被夹紧，两处能承受轻微手持扰动，并能用预期退出动作顺畅解除。这里的“锁定”只是可释放的挂接，不是机械扣死。【确定性：中】

- **“下端先脱、上端后脱”的自检：**把下端明确理解为**握把附近接口**、上端为**窄端接口**。先用无尖头、无锋利附件的试配杆，人工缓慢改变板与杆的相对角度，观察近握把接口能否先解除，而窄端仍短暂承力、随后退出。可在接口旁做对比色标记，以侧视录像复核。静态检查只能发现干涉，不能证明实际快速运动的脱离时序；之后只能在受控场地进行低能量验证。**红线：不得在室内、有人或动物的方向，或无合适挡护的场地，以锐利镖验证接口。**【确定性：高】

- **卡滞：**先查两孔间距误差、凸榫倾角不一致、孔口毛刺、槽沿台阶及杆身弯曲。用可擦记号找接触点，只修阻碍退出的局部；不要一遇卡滞便把两孔全面扩大。**红线：只要存在需猛甩、硬拽才能脱开的情况，就停止投掷验证。**【确定性：高】

- **提前脱开：**先查孔是否过大、凸榫有效挂接是否不足、杆是否没有装到正确位置，以及近握把接口是否根本没有承力。应纠正接触位置或重做不合格接口，而不是加摩擦垫、深挖沟槽或增加倒扣来留住杆。【确定性：中】

- **镖打转：**可能来自接口偏离杆轴、两孔受力不对称、杆在槽中侧滚，或杆本身弯曲及配重不当。先排查板与杆的中心线、两榫一致性和脱离是否偏向一侧；不能仅凭飞行打转就认定孔径有误。不要把这种问题直接归咎于使用者手法。【确定性：中】

## 工具与工序

- **无车床的最小工具集：**锯、手钻或电钻及配套钻头、浅圆凿或适合修槽的圆底刨、木锉／半圆锉、刮刀与砂纸；另需直尺、角尺、卡尺、画线工具、夹具和钻孔垫木。试配杆或等径圆模板同样属于必需工装。**红线：钻孔、凿槽时必须夹牢工件，不能手持小板钻孔；佩戴护目镜，打磨控制粉尘。**【确定性：高】

- **推荐顺序：**选料检查 → 下料并保留加工余量 → 校平与画中心线 → 粗开浅槽 → 试放杆、转印接口 → 钻孔并试修退出路径 → 修外轮廓、握把及指凹槽 → 精修槽与孔口 → 砂光 → 薄涂表面处理 → 完全固化后复验。较方正的毛坯便于夹持和钻孔，不必一开始就削出全部曲线。【确定性：高】

- **不可随意交换的先后：**必须先确定实际凸榫与杆在槽中的高度，才能最终定孔位及孔口形状；采用胶合孔衬时，必须先胶合稳定再开最终孔；最终握把削薄之前，应确认孔周余料。粗开槽与粗钻孔并不存在普遍“绝不能互换”的规则，但**最终孔形不能先于接口试配，最终验收不能先于表面处理固化**。【确定性：高】

## 验收标准

- **结构与承托合格：**正常握持和轻微手持扰动时，杆能稳定落槽、两接口正确就位；杆身不被夹紧，握把不迫使手指接近退出路径；板、孔缘和凸钮根部无裂纹、松动、尖锐毛刺或脱层。**硬指标是结构完整与手部净空，而不是必须达到某个重量。红线：出现裂纹、永久变形或孔衬松动，立即停用。**【确定性：高】

- **释放与重复性合格：**以相同装填方式重复检查，均能出现近握把接口先解除、窄端接口随后顺畅解除；不需硬拽，不发生单侧挂住、明显横向弹跳或新生损伤。慢动作检查后仍须受控低能量验证，不能把一次成功当作通过。**红线：任何一次异常挂接、不可解释的提前脱开或脱离次序反转，都应退回修整与检查，不进入正常使用。**【确定性：高】
