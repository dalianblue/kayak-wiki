# PengYi 澎逸羽船系列

![PengYiLogo](img/%E6%8F%92%E5%9B%BE01.png)

> 开启你的冒险之旅 🚣

澎逸羽船系列是一款蒙皮折叠皮划艇，致敬阿拉斯加划艇旅行设计，轻量便携，易于组装存储。

---

## 产品特点

![羽船39](img/%E6%8F%92%E5%9B%BE02.png)

- **轻量便携** - 船净重仅13.2-15.5公斤，包装尺寸小巧
- **舒适悬挂座椅** - 12毫米厚闭孔泡沫座位靠背和缓冲
- **优质材料** - 6061-T6铝合金框架 + TPU四层复合甲板 + 海帕龙船底
- **快速组装** - 无需工具，按图示步骤轻松组装
- **易于存储** - 拆解后可收入背包，存放于阴凉干燥处

## 快速组装指南

![羽船组件](img/%E6%8F%92%E5%9B%BE03.png)

组装仅需20步，详细步骤请参考[完整说明书](羽船系列说明书.md)：

1. **安装船头/船尾框架** - 将小型板固定到骨架上，插入脚踏板
2. **展开蒙皮** - 打开魔术贴搭扣，将框架滑入蒙皮
3. **安装龙骨延伸杆** - 连接船头船尾，展开并锁定
4. **安装座舱圈和座椅兜** - 滑入指定位置
5. **安装中间套管接头** - 对齐管子并连接
6. **安装大型型板** - 放置并卡入到位
7. **安装甲板栏杆** - 通过型板孔插入并锁定
8. **安装座椅和充气** - 固定座椅织带，给气室充气

## 维护与保养

### 框架保养
- 使用2-3个月后拆卸，用淡水清洗内外
- 使用润滑剂喷涂管件装配位置
- 每两个月完全拆解保养一次

### 蒙皮保养
- 划艇后用海绵去除积水
- 避免在尖锐岩石上拖拽
- 小破损可用修补包修复

### 存储要求
- 保持清洁干燥
- 可组装或拆卸状态存放
- 延长杆需完全分开

## 可选配件安装

### 方向舵
将方向舵销插入钥匙孔旋转180度，连接控制绳到脚踏板即可。

### 海袜
防水安全配件，防止仓内进水，闪亮面朝向框架，logo在右侧。

### 储物仓
连接舱口圈，通过甲板织物袖子连接密封圈，用插扣锁定。
