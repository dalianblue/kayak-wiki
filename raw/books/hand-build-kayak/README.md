# 艺术级皮划艇建造技术

本书原作者吴树升先生授权公开，遵循 CC BY-SA 4.0 协议。

## 📖 内容简介

本书详细介绍了艺术级皮划艇的完整建造过程，包括：

- **设计因素** - 皮划艇性能参数分析
- **型线图绘制** - 图纸绘制原理与识图方法
- **建造基础** - 所需材料、工具和空间
- **形板放样** - 模板制作方法
- **木条加工** - 形板和龙骨加工
- **船体建造** - 船体和甲板制作
- **玻璃纤维铺设** - 外层处理
- **配件制作** - 仓口、座椅、靠背等
- **船体装配** - 各部件组装
- **船桨制作** - 船桨工艺
- **维护修理** - 日常维护和损伤修复

## 📝 前言

皮划艇具有非常久远的传承和深厚的文化底蕴。据考证起源于格陵兰岛，是阿留申人和纽因特人发明的。皮划艇运动也是奥运会比赛的一个项目，1924 年作为表演项目进入奥运会，1936 年皮划艇成为奥运会正式比赛项目。

在当前全民健身的需求下，以及青山绿水，金山银山的环境治理因素促进下，皮划艇运动在国内得以蓬勃发展。国内日益增长的对于皮划艇器材需求和器材发展缓慢出现了供需矛盾。国内虽然有皮划艇的生产厂家，但是满足不了个性化定制、艺术化定制等要求。在国外皮划艇定制工艺和庭院式皮划艇加工技术非常成熟。在这个前提下，我把我学习的国外皮划艇制作知识结合澎逸工匠坊艺术级皮划艇制造经验开始撰写这本《艺术级皮划艇建造技术》。抛砖引玉希望可以给国内皮划艇运动的发展提供一点点助力，满足国内个人制作以及个性化的需求。也希望可以带动皮划艇界各位朋友的创造激情，让皮划艇制作技术和皮划艇运动文化在国内发展的更好。

从开始计划这本书到书籍完成经历了一年多的时间，比我想象的撰写过程复杂了很多。提纲的总结梳理规划、照片的拍摄、内容的撰写到校对审核是非常庞大的工作量。在这一年的时间里也经历了很多的事情：2019 年 6 月我自己身体出现了点问题，身体的调理花费了很长的时间；2019 年 8 月澎逸运动用品公司也开始经历转型；在 2020 年 1 月开始还经历了冠状病毒肺炎的疫情。林林总总不足二一，能够完成这本书的出版也是欣慰。

在这个过程中，非常感谢我爸爸妈妈对我的鼓励和支持，给我了精神动力；感谢我的亲弟弟吴树成对我全方位的支持，没有弟弟的支持就不会有这本书诞生；特别感谢张薇薇女士在我生病期间的疏导鼓励，以及在撰写过程中的督导，让这本书能够完成；感谢四川张俊中在我撰写的同时对书稿的审核和校对，给原始稿件指出了非常多的问题，打印标注给我，方便我修改，让我能够更认真更细心的对待这本书；同时也感谢皮划艇界的各位朋友的支持和鼓励。
