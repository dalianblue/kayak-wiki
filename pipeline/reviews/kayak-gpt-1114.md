- **[错误／过度概括]** “英国人……把海划从探险家专属变成大众运动” → 皮艇从来不只是探险家的器材；在原住民社会是日常生计工具，欧洲大陆也有独立的休闲划艇、俱乐部、折叠艇工业和远征传统。应改成“英国在现代休闲海划与硬壳远征艇设计的发展中发挥了重要作用”。（置信度：高）

- **[确认／限定]** “John MacGregor 的 Rob Roy canoe 灵感取自北美原住民皮艇” → 基本成立，但其设计吸收了北美 canoe 与 kayak 等见闻，并使用木质建造、甲板和帆装，是混合性休闲旅行艇，不是传统皮艇的直接复制。首条著名 Rob Roy 建于 **1865 年**。（置信度：高）

- **[确认／补足]** “1866–1869……三本书” → 所列三本书的出版年份分别为 **1866、1867、1869**，可保留；但第三本完整书名还包含 Nile、Red Sea、Gennesareth 等，不只约旦河。MacGregor 此期间还出版过涉及另一条 Rob Roy 帆艇的著作，故宜写“出版了包括以下三部在内的旅行著作”，而非暗示其全部作品只有三本。（置信度：高）

- **[错误]** “记录了最早的现代意义海划远征” → 很多行程发生在河流、湖泊等内陆水域，而且“最早”需要明确现代海划的定义与比较对象。建议改为“成为现代休闲划艇旅行的重要早期范例”。（置信度：高）

- **[确认／补足]** “1907 年 Klepper 量产折叠艇” → 1907 年开始商业生产的基本时间线成立。但须补 **Alfred Heurich 于 1905 年制作早期可用折叠艇，Johann Klepper 随后将其商业化**，避免把发明和工业化都归给 Klepper。（置信度：高）

- **[存疑]** “1929 年日产 90 条；1930 年代中叶欧洲……50 万条” → 这些是常见二手统计，必须交代是生产峰值、公司宣传还是行业估计；“欧洲在用总数”也不等于 Klepper 产量。没有可追溯统计来源，不宜保留为精确、无争议的数字。（置信度：中）

- **[确认／限定]** “Franz Romer，1928……58 天……抵圣托马斯” → 人名更常写作 **Franz Römer**；1928 年从加那利群岛到圣托马斯的跨洋段及约 58 天的叙述基本成立。他的完整航行并非从 Las Palmas 才开始，应区分出航起点与跨大西洋长航段。（置信度：高）

- **[存疑／数字修正]** “20 尺……5,060 km” → 所用改装折叠艇常记为约 **6.4 米，即约 21 英尺**；“20 尺”最多是粗略值，且中文“尺”容易被误读为市尺，应写“英尺”。航程数字应说明按什么路线计算，不要当成仪器测得的唯一精确距离。（置信度：中）

- **[确认／限定]** “首位乘海划艇横渡大西洋者” → 常被认作首位完成该壮举者，但他使用帆装，不能写成“首位全程纯划桨横渡者”。建议：“通常被认为是首位以皮划艇完成大西洋横渡者，航行中使用了帆。”（置信度：高）

- **[错误／确定性过高]** “误入 Okeechobee 飓风殁于海上” → 他在离开波多黎各、继续向纽约方向航行后失踪，通常被推测死于 **1928 年 Okeechobee／San Felipe 飓风**。缺乏目击或确证，不能写成已查明的死亡过程。（置信度：高）

- **[错误]** “Oskar Speck……七年 23,000 km” → 博物馆及通行传记资料通常记为 **1932—1939 年、约 50,000 公里**。这仍是总航程概算，但 23,000 公里不符合常见的完整旅程口径。（置信度：高）

- **[确认／补足]** “Ulm 出发……抵澳洲托雷斯海峡” → 起点与大方向成立；终点宜具体写为 **1939 年 9 月抵达托雷斯海峡的 Saibai 岛**。他并非自始至终按一个预定“德国到澳洲远征”计划行动；抵澳后因战争成为德国敌国国民而被拘留，也是重要事件背景。（置信度：高）

- **[存疑]** “折叠艇……是便携化的因纽特母型，还不是新船型” → 欧洲折叠艇确实受到北极皮艇启发，但也形成了自己的结构、尺寸、双人配置和帆装传统。“不是新船型”既无统一判据，也掩盖了设计创新。应改成“将蒙皮框架原理发展为可拆装的工业制品”。（置信度：高）

- **[确认／限定]** “1950s 玻璃钢艇登场” → 作为现代复合材料皮艇发展的概括可以保留，但不要理解为所有海划艇市场在此时已由玻璃钢主导。（置信度：高）

- **[错误／时间口径不明]** “1984 年滚塑聚乙烯出现” → 聚乙烯皮艇、旋转模塑工艺与具体海划艇品牌的上市时间不是同一件事。塑料皮艇发展在 **1970 年代已有先例，1980 年代显著扩展**；若保留 1984，必须明确是哪个品牌、型号或哪类生产工艺的节点。“材料革命收官”也不是可核验的历史事件。（置信度：高）

#### Anas Acuta 与 Nordkapp：核心更正

- **[错误]** “Anas Acuta（Ken Turner 依其收藏的西格陵兰艇测绘设计……）” → 原型采集者应是 **Kenneth ‘Ken’ Taylor**，不是 Ken Turner。Taylor 在 **1959 年**于西格陵兰 **Illorsuit**——旧拼法常见 Igdlorssuit——取得一条当地为他建造的皮艇，并带回英国。（置信度：高）

- **[补足]** “依其收藏……测绘设计” → 必须分开以下角色：
  - 原型艇的格陵兰建造者通常记为 **Emanuele／Emanuel Korneliussen**，姓名转写随资料而异；
  - 原型取得者是 **Ken Taylor**；
  - **Duncan Winning** 测绘、传播了该艇的线型资料；
  - **Geoffrey ‘Geoff’ Blackford** 据此发展出与 Anas Acuta 直接相关的英国建造版本。
  
  把这些工作都归给一个英国“设计者”，会抹去原住民建造者及设计转译过程。（置信度：高；原建造者姓名的具体拼法：中）

- **[错误]** “Venture of Llandysul 建造，约 1970–71” → **不能把这个厂名作为 Anas Acuta 商业定型制造商保留**。通行且较可靠的船型史是：Blackford 的版本约在 **1971 年**成形，随后由 **Peter Liddell 与 Kenneth ‘Ken’ Littledyke** 等人参与玻璃钢版本的发展，**Valley 在 1972 年开始商业生产**。1971 的设计／原型节点与 1972 的商业生产节点不应合并。（置信度：高；早期各版本的逐年细分：中）

- **[确认／建议替换原句]** Anas Acuta 段可改为：
  
  > “Anas Acuta 的谱系可追溯至 Ken Taylor 于 1959 年从西格陵兰 Illorsuit 带回的当地皮艇。Duncan Winning 的线型测绘成为英国建造者的重要依据；Geoff Blackford 约于 1971 年发展出相应版本，Peter Liddell、Ken Littledyke 等参与其玻璃钢化，Valley 于 1972 年开始商业生产。”
  
  这是比“Ken Turner、1970–71、Venture”更准确的基本时间线。（置信度：高）

- **[确认／限定]** “Nordkapp（Frank Goodman……1975……Valley）” → **Frank Goodman 与 Valley、1975 年北挪威远征需求的联系基本正确**。主设计者署名可用 Frank Goodman，不应无依据扩写其法定名字。设计发展资料中也常提到 Valley 的 **Barry Nethercott**，如要详列共同开发者，应另引厂史或当事人资料。（置信度：高；协作角色细分：中）

- **[错误／中文歧义]** “1975 年挪威角远征” → **Nordkapp 是挪威北角，英语 North Cape**，不是“挪威角”。宜写“1975 年前往挪威北角的 British Norway Expedition”。（置信度：高）

- **[错误／设计关系失真]** “放大设计” → Nordkapp 不是简单将 Anas Acuta 等比例放大。它为载货与远征需求发展出更大容积及不同船体特征，尤其不应忽略 **Anas Acuta 的硬舭与 Nordkapp 较圆顺横剖面之间的区别**。（置信度：高）

- **[确认／年代辨析]** “Nordkapp：1975 还是 1976？” → **以设计产生和首次相关远征使用为节点，采用 1975 年最妥当**。1976 若出现在某份资料中，可能指后续商业供应、特定版本或其他节点；没有明确证据，不应把其起源整体后移为 1976。（置信度：高）

- **[错误／艇型概括失准]** “两艇把……低甲板、高初速、远征载货……写成通用语法” → Anas Acuta 与 Nordkapp 的容积和用途并不相同，不能同时概括成低甲板的载货远征艇。“高初速”不是这段历史中有明确出处的共同设计指标，也容易与初稳性混淆。建议分别写低容积、贴近格陵兰线型的 Anas Acuta，以及为远征载荷发展的 Nordkapp。（置信度：高）

- **[存疑／限定]** “1986 年……首次环不列颠＋爱尔兰双岛划行” → 三人及 1986 年旅程的基本记述可保留，但“首次”必须限定为**一次旅程中连续环绕英国本岛与爱尔兰岛**等具体纪录类别。它不是首次环英国本岛；**Paul Caffyn 与 Nigel Dennis 在 1980 年已有著名的英国本岛环划**。“不列颠”也不宜用来含混代指整个英国及附属岛屿。（置信度：中；1980 年英国本岛环划：高）

- **[确认／待核书目]** “《Commitment and Open Crossings》1992” → 书名与该旅程关联基本正确，1992 年的书目年份可暂保留，但上线前应核对所采用版次及作者页，不要用旅行发生年份代替出版记录。（置信度：中）

- **[存疑／过度概括]** “今天的远征海划艇默认设定，就是这条英式路线的产物” → 英式路线影响很大，但现代海划艇还包含北美、斯堪的纳维亚及其他设计传统。该句应限定为“现代英式远征海划艇及受其影响的众多艇型”。（置信度：高）
