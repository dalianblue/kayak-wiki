# 放样：从型线图到形板

> 把图纸上的型值坐标变成 1:1 实物模具。手工=钉子+打包带的光学曲线；电脑=AutoCAD 坐标输入+激光切割。

## 木板尺寸计算（先算料再画线）

从型值表读每站数据^[raw/books/hand-build-kayak/第4章-形板放样方法.md]：

```
形板长度 = 甲板峰值 − 船体峰值          （基准在外: 如 195−71=124mm）
                                      （基准在内: 如 181−(−72)=253mm）
形板宽度 = 最大外形半宽 × 2
下料尺寸 = 形板尺寸 + 20~30mm 加工余量
```

## 手工放样四步（钢板尺+直角尺+钉子+塑胶打包带）

1. **绘基准**：宽度中心线 + 高度基准水线，十字必须垂直——一切坐标的原点
2. **钉半宽点**：按半宽型值表（甲板峰值/船体峰值/各纵剖线），钉子在中心线两侧定位
3. **钉高度点**：按高度型值表（各水线距基线高度 × 距中线半宽）+ 最大外形点
4. **弹曲线**：塑胶打包带贴钉形成自然光顺曲线（弹性=平顺过渡），铅笔描形，线锯切割+打磨

要点：打包带弹性刚好——太软变折线，无弹性不顺滑。近距点可略一个，曲线更光顺。

## 电脑放样（AutoCAD 八步）

型值表三部分读坐标：半宽值（X=半宽,Y=高度）、高度值（X=半宽,Y=水线，与半宽表相反）、最大外形（X=半宽,Y=高度）→ 多点命令输入坐标 → SPL 曲线连接 → MI 镜像 → L 画基准线 → O 偏移出**中心龙骨孔**（100×50mm 木方贯穿全船形板）→ TR 修剪 → 发激光切割（20mm 板排版加工）。

**龙骨孔原则**：孔位以 0 水线为基准统一定位；矩形完全在形板轮廓内=用全尺寸龙骨；部分越界=下部缩小/切掉对应位置；完全在外=改装在艏艉形板上。间隙容差吸收龙骨变形误差。

## 艏艉形板与配件

艏艉形板偏移表以结合站位为 X 原点、基准水线为 Y 原点，给出底/顶/切边坐标。艇首艇尾形板需预留形板龙骨安装位（100 宽）与站位形板卡槽（20 宽）。座舱圈/支撑板按配件型值表同法绘制。
